# All About PyTorch

The course is free and the original materials are at [mrdbourke/pytorch-deep-learning](https://github.com/mrdbourke/pytorch-deep-learning). If you want to learn PyTorch, go there. This repo is just my working copy.

## Notebooks

| Notebook | What it covers |
|---|---|
| `00_PyTorch_Fundamentals.ipynb` | Tensors. Creating them, dtypes, indexing, reshaping, matrix multiplication. Random seeds and device-agnostic code. |
| `01_PyTorch_Workflow.ipynb` | The basic workflow on a linear regression problem. Build a model with `nn.Module`, pick a loss and optimizer, write the training and testing loops, save and load. |
| `02_PyTorch_Neural_Network_Classification.ipynb` | Binary and multi-class classification. Why stacked linear layers can't separate non-linear data and what activation functions fix. Plotting decision boundaries. |
| `03_PyTorch_ComputerVision.ipynb` | CNNs. `nn.Conv2d` and `nn.MaxPool2d`, building a TinyVGG model, confusion matrices. |
| `04_PyTorch_Custom_Datasets.ipynb` | Loading your own images. `ImageFolder`, writing a custom `Dataset` class, transforms and data augmentation. |
| `05_PyTorch_Modular.ipynb` | Moving notebook code into Python scripts so you can run training from the command line. |
| `06_PyTorch_TransferLearning.ipynb` | Pretrained models from `torchvision.models`. Freezing the backbone, swapping the classifier head, matching the input transforms the model was trained with. |

## Setup

```bash
git clone https://github.com/Rohan08-21/All-About-PyTorch.git
cd All-About-PyTorch

python -m venv env
env\Scripts\activate          # Windows
source env/bin/activate       # macOS or Linux

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt

jupyter lab
```

## Environment

These notebooks were run on:

| | |
|---|---|
| Python | 3.14.7 |
| torch | 2.14.0+cu130 |
| torchvision | 0.29.0+cu130 |
| CUDA | 13.0 |
| GPU | NVIDIA RTX 4080 Laptop, 12 GB |

The exact versions are printed by a cell at the top of notebook 00, so you can check what it ran on without cloning.

If you are on a different CUDA version, get the right install command from [pytorch.org](https://pytorch.org/get-started/locally/) instead of using the index URL above. For CPU only, drop the `--index-url` flag and install torch normally. The notebooks use `device = "cuda" if torch.cuda.is_available() else "cpu"`, so they run either way. The later ones are slow without a GPU.

## Data

Datasets are not in the repo. Notebooks 04 and 06 use a small subset of [Food101](https://pytorch.org/vision/stable/generated/torchvision.datasets.Food101.html). The notebooks expect it here:

```
data/<dataset_name>/
├── train/
│   └── <class folders>
└── test/
    └── <class folders>
```

Run the download cell at the top of the notebook to get it, or build your own subset with `torchvision.datasets.Food101`.
